# Key-Value Redis Project

A high-performance key-value caching service built with modern web technologies.

## Features

- Fast and efficient key-value storage
- RESTful API endpoints for data operations
- Modern React frontend with TypeScript
- Real-time data validation
- Responsive design
- Production-ready architecture

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Development

The project uses:
- React with TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- Radix UI for accessible components

## Deployment

The application can be deployed to any static hosting service that supports Node.js applications.
